# Welcome to Plutus Debugger

The **Plutus Debugger VSCode Plugin** brings professional debugging tools to Cardano smart contract developers. 
Built to provide step-through debugging, variable inspection, and breakpoint capabilities directly within your favorite IDE.

## Features

- **Breakpoints**: Set breakpoints in your Plutus (Haskell) code.
- **Variable Inspection**: View the current state of variables on the stack.
- **Gas Profiling**: Track ExUnits consumption across execution.
- **Simulation**: Test scripts with mock ledger states before deploying.
