# Frequently Asked Questions (FAQ)

### What versions of Plutus does this plugin support?
We support **Plutus V1**, **Plutus V2**, and the recently released **Plutus V3**.

### Can I debug directly on-chain?
No. The debugger runs locally against an offline node or simulator. On-chain debugging is not supported as the ledger does not emit granular execution traces in real-time.

### Does it support Aiken?
Currently, the plugin focuses on Plutus Tx (Haskell). Aiken has its own set of toolchains, though we plan to add Aiken trace format support in the future.
